# 「自动账本」前端设计方案（Android）

> 配套文档：《设计方案-自动账单管理App.md》
> 本文档覆盖：信息架构 · 视觉规范 · 逐页线框 · 组件库 · 交互动效 · Flutter 实现映射

---

## 一、设计原则

| 原则 | 落地 |
|------|------|
| **零打扰** | 采集静默、反馈环境化（附录 C），界面永远等用户来，不追着用户跑 |
| **一秒看懂** | 首页打开即见"花了多少、最近买了什么"，零学习成本 |
| **数字优先** | 金额用大字号等宽数字，视觉层级：金额 > 分类 > 商户 > 时间 |
| **信任感** | 克制的配色、真实数据说话、隐私状态可见（渠道中心一眼确认） |

**品牌调性**：干净、克制、可信赖。不是游戏化的记账玩具，是一个安静的财务助手。

## 二、信息架构与导航

### 2.1 底部导航（4 Tab + 中央按钮）

```
┌─────────────────────────────────────────┐
│                                         │
│   首页    报表   ┌───┐   预算    我的     │
│                 │ ＋ │                   │
│                 └───┘                   │
└─────────────────────────────────────────┘
```

| Tab | 内容 | 图标 |
|-----|------|------|
| 首页 | 今日/本月总览 + 最近交易流 | 🏠 |
| 报表 | 饼图/趋势/热力日历/分类排行 | 📊 |
| ＋ | 手动记一笔（Bottom Sheet 弹出，非页面跳转） | ＋ |
| 预算 | 月度预算 + 分类预算 | 🎯 |
| 我的 | 设置/渠道/类目/隐私/导出 | 👤 |

**二级页面（推送进入，无 Tab）**：账单日历、渠道中心、待确认队列、交易详情、类目管理。

### 2.2 路由表

```

/reports              → 报表

/settings/privacy     → 隐私与数据

## 四、逐页线框与设计说明

### 4.1 首次启动流程

```

### 4.8 待确认队列

首页顶部条件显示入口（"3 笔待确认"胶囊），进入后列表展示低置信度交易，每条右侧直接内嵌分类快捷选择，全部处理完显示空态"全部确认完毕 ✓"。

- 轻通知开关（信任建立期）
- 数据导出 CSV/JSON

## 六、交互动效

| 场景 | 动效 | 时长 |
|------|------|------|
| 新交易插入列表 | 顶部滑入 + 高亮渐隐 | 300ms |
| 记一笔保存成功 | Sheet 下滑关闭 + 触觉轻震 | 250ms |
| 页面转场 | 平台默认（Material 3 共享轴） | 系统 |
| 饼图首次出现 | 扇区从 0° 扫描展开 | 600ms ease-out |
| 金额变化（总览卡） | 数字滚动 | 400ms |
| 隐私打码切换 | 金额模糊渐变 | 200ms |

> 原则：动效只用于**状态变化确认**（新数据到了、保存成功了），不做装饰性动画。系统"减弱动态效果"开启时全部降级为直接切换。

## 八、Flutter 实现映射

### 8.1 目录结构

```
lib/
├── core/
│   ├── theme/          # Design Tokens → ThemeData / ThemeExtension
│   ├── router/         # go_router 路由表
│   └── db/             # drift + SQLCipher
├── features/
│   ├── home/           # 首页（Controller + Page + Widgets）
│   ├── reports/
│   ├── record/         # 记一笔 Bottom Sheet
│   ├── budget/
│   ├── calendar/
│   ├── channels/       # 渠道中心
│   └── settings/
├── shared/
│   └── widgets/        # TransactionTile / AmountText / Charts …
└── main.dart
```

### 8.2 技术选型

| 项 | 选型 |
|----|------|
| 状态管理 | Riverpod |
| 路由 | go_router |
| 图表 | fl_chart（饼图/折线）+ 自绘环形进度 |
| 本地库 | drift + SQLCipher（与 `:collector` 进程共享同一加密库，WAL 模式） |
| 日历 | 自绘 TableCalendar 定制 |
| 触觉 | `HapticFeedback.lightImpact` |

### 8.3 关键实现点

1. **首页秒开**：`SELECT ... ORDER BY occurred_at DESC LIMIT 20` 首帧渲染骨架 → 数据替换；无任何网络请求。
2. **与 `:collector` 进程共享数据**：两个进程访问同一 SQLCipher 库（WAL），主进程用 `drift` 的 Stream Query 监听表变化——后台写入新交易时，若 App 恰好在前台，列表自动刷新插入动画。
3. **金额等宽**：`TextStyle(fontFeatures: [FontFeature.tabularFigures()])`。
4. **隐私眼睛**：全局 `AmountPrivacyProvider`，一处切换所有 `AmountText` 同步打码。
5. **主题**：`ThemeExtension` 定义全部 Design Token，`light()` / `dark()` 两个工厂，Material 3 `ColorScheme.fromSeed` 兜底。

## 九、无障碍清单

- 支持系统字体缩放至 1.3x 不破版（弹性布局）
- 交易列表语义：`Semantics(label: "美团外卖，支出35.8元，餐饮外卖，14:32")`
- 对比度：正文 ≥ 4.5:1，次要文字 ≥ 3:1
- 触控目标 ≥ 48×48dp
- 动效跟随系统"减弱动态效果"
