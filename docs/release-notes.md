# 账迹 BillTrace v0.4.3

这一轮做了一次全量代码审查，把查出来的 26 个问题全部修掉。重点是**别再让你误判自己的 App 坏了**，以及**别再一键丢数据**。

## 数据可靠性

- **读取失败不再伪装成「未授权」**。以前后端一出异常，首页会打出 `¥NaN`、`今日 ¥NaN · undefined 笔`，同时告诉你"还没开启通知使用权"——你会去反复开一个已经开好的权限。现在读取失败会显示一条红色横幅，不再展示授权引导，金额位显示 `¥—`。
- **删除账目需要确认，且 6 秒内可撤销**。以前在详情里点一下「删除这条」就直接没了，没有确认也没有撤销。
- **同一笔钱不会再记两次**。通知与短信同时到达、或连点「导入历史短信」时，以前可能并发插入重复记录；现在判重是原子的，回填也只允许同时跑一趟。
- **导出的 CSV 更结实**。字段统一加引号、内部引号翻倍，商户名里的引号不会再把列搞乱；以 `= + - @` 开头的值会前置单引号，避免在 Excel 里被当公式执行（商户名可能来自短信正文）。
- **详情里能看到「原始文本」了**。这个字段一直存在数据库里，但有个 bug 让它从没送到界面上——之前那里永远显示"（没有原始文本）"，你看不到一条记录为什么被归错类。

## 权限与隐私

- **去掉 `INTERNET` 权限**。App 只读本机通知与短信、只写本地 SQLite，从头到尾没有任何网络请求，声明它既多余又和「不联网」的承诺矛盾。
- **关掉本地文件访问开关**。加载自带页面用不到它，开着反而让页面能读设备上任意本地文件。
- **WebView 只允许回到应用自己的页面**，不让外部站点出现在有数据桥的窗口里。
- **少暴露 6 个桥接口**给网页层。
- 数据仍只存本机应用私有目录，未加密；导出需要你主动操作。

## 报表与其他

- 预算输入非法值（字母、负数）会提示，不再静默把原预算清掉；留空=保持不变，输入 0=清除。
- 触控目标加到 44×44 以上；系统开启「减弱动态效果」时停用过渡动画；可点行对读屏软件播报为按钮。
- 修正文案：商户归类规则实测 111 条，改称「110+ 条」。
- 招行 logo 不再被套在所有银行的工资到账上。

## 升级

与 v0.4.1 / v0.4.2 同一签名，直接覆盖安装即可，权限不会丢。（只有从 v0.4.0 及更早的调试签名版本升级才需要先卸载。）
