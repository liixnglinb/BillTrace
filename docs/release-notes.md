# 账迹 BillTrace v0.5.0

这一版加了「软件内检查更新」：不用再自己去下载页看有没有新版。

## 检查更新

- **「我的」页版本那一行右侧多了「检查更新」**。点一下就会问一次服务器上有没有新版本；有的话弹出卡片，写明新版本号、安装包大小和这次改了什么。
- **点「更新并重启」开始下载**，卡片里有进度条，系统通知栏也有一条进度；退到后台下载不会中断。
- **下载完成后点「安装」**，会打开系统的安装界面 —— 装不装、什么时候装，由你自己点「下一步」决定。第一次装需要先允许「账迹」安装未知来源的应用，App 会直接把你带到那个开关。

## 关于联网（这一版新开了这个口子，说清楚）

以前这个应用完全不联网，安装包里连 INTERNET 权限都没申请。这一版为了能自动识别新版本，
**只有「检查更新」和「下载更新包」这两件事会联网**：检查更新只是 GET 一次版本信息，不上传任何数据；
下载走系统的下载服务，同样只下不上。你的账目、短信与通知内容依然只存在本机，不会离开这台设备。

## 升级

与 v0.4.1 起同一签名，直接覆盖安装即可，通知使用权和短信权限都不会丢。
