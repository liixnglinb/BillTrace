# 账迹 BillTrace v0.4.2

这一版把「权限开不上、软件用不了」这一类问题连根修掉，并顺手修了报表图表的显示错误。

## 权限

- **通知使用权入口逐级兜底**：原生「通知使用权」页 → 小米/红米的权限编辑器 → 设置首页。之前只试一个入口，国产 ROM 上打不开就只剩一句提示，表现为「点了没反应」。
- **短信权限被系统记住「不再询问」后不再空转**：Android 11+ 连续拒绝两次后系统不会再弹框，此前点「导入短信账目」毫无反应。现在会识别这种状态并把按钮换成「去设置里开启」，直达应用权限页。
- 找不到入口时，界面会直接给出对应厂商的手动开启路径。

## 报表图表

- **近 7 天支出**：没有支出时不再画七根等高短线（那看起来像一张坏掉的图，而新用户恰好就是这个状态），改为明确的「近 7 天还没有支出」。
- **近 30 天分类**：只列前 6 类时，剩下的钱之前既不进堆叠条也不进列表——占比加起来不到 100%，「合计」也对不上可见行，右边一段灰槽像没画完。现在合并成「其余 N 类」一行，堆叠条填满 100%，合计与明细一致。
- **预算环**：描边虚线长度与实际圆周长不一致（452 与 452.389），满额时收尾有缝隙，现在统一按真实半径计算。

## 更新体验

- **改用固定正式签名**。此前每次构建都用新生成的调试密钥，导致每个安装包签名都不同，覆盖安装必报签名不一致、只能先卸载——而卸载会把已开启的通知使用权和短信权限一起清掉。现在签名恒定，覆盖安装保留权限。
- 安装包从约 547 KB 降到 **119 KB**（商户图标重编码为 WebP，并按实际显示尺寸缩放）。

## ⚠ 从 v0.4.0 及更早版本升级请注意

因为签名从调试密钥换成了正式密钥，**这一次必须先卸载旧版本再安装**，这是最后一次。此后覆盖安装不会再掉权限。

## 数据说明

账目存在本机应用私有目录的 SQLite 里，不联网、不上传、不需要账号，卸载即删除。当前为应用私有存储，**未做全库加密**。

## 已知不做的

无障碍引擎（脆弱且要高危权限）、全库加密、云同步。
