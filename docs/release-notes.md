# 账迹 BillTrace v0.4.4

这一轮把「账多了以后」的体验补齐：以前账目一多，列表和搜索其实都在悄悄只看你最近的一部分，报表的分类占比还会排错。都在这版修掉了。

## 账目多了以后

- **列表不再只显示最近 200 条**。以前「我的」页写着「共 5000 条记录」，列表却只给看最近 200 条，也没有任何提示。现在列表底部有「加载更多（还有 N 条）」，点一下往后翻一页，翻到底按钮自动消失。
- **搜索能搜到全部账目了**。以前搜索只在你已经翻出来的那一小段里找，没翻到的账搜不到也不提示。现在搜索走数据库全量检索——商户、备注、账户、分类名、金额都能搜（比如直接输 `35.8` 就能找到那笔账）。
- **搜索失败不再说成「没找到」**。以前读库一出错，搜索会显示「没找到相关记录」，等于告诉你"你的账里没有这条"。现在会明说「搜索没成功，是账本读取的问题」。「加载更多」读库失败也一样：提示重试，按钮保留，不会把入口藏掉。

## 报表修了三处会看错的地方

- **分类占比按金额排序了**。以前「近 30 天分类」只画前 6 类、其余并入「其他 N 类」，但内部把排序结果装进了一个无序容器，等于**随便挑了 6 类**——花钱最多的那几类可能正被塞进「其他」里看不见。现在严格按金额从大到小。
- **「其余 N 类」看得见了**。它的颜色和背景条只差 1.4:1，几乎隐形，而它恰恰是用来解释"剩下的钱去哪了"的。现在和每一段之间都有分隔线。
- **柱形图每根都看得清**。最矮的几根以前淡到几乎看不见；「今天」那根现在除了颜色更深，日期文字也加粗——不依赖颜色也能认出是今天。预算环的进度色加深，超支时依然是红色。

## 界面整体校准

- **所有文字对比度按 WCAG AA 标准逐像素校准过**：4 个页面、4 个弹层、错误横幅，159 组文字/背景全部达标，不再有"深灰底上配中灰字"的组合。分类小标签从原来的亮色填充换成同色系深墨色，看起来沉稳了一点，但在浅底上真正读得清。
- **冷启动不再闪一屏黑**。以前打开 App 会先黑一下再变白。
- **底部导航栏改成不透明**。以前半透明底上，导航文字的清晰度会跟着下面滚过的内容变，实测最差时接近看不清。
- 按钮在鼠标悬停时有了反馈；被禁用时能一眼看出不可点。

## 界面拆分成三层

界面从单个 1300 行的 HTML 拆成结构 / 样式 / 纯逻辑 / 交互四个文件，纯逻辑部分现在有 32 条不依赖浏览器的单元测试（连同 Java 侧 47 条一起进构建门禁）。这对使用者没有直接影响，但以后每次出包前，会有更多"改坏了也当场拦下"的检查。

## 升级

与 v0.4.1 ~ v0.4.3 同一签名，直接覆盖安装即可，权限不会丢。（只有从 v0.4.0 及更早的调试签名版本升级才需要先卸载。）
